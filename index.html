Aplicación real de los grafos

Dijkstra para ahorrar energía en redes de sensores

Cómo los caminos mínimos ayudan a elegir rutas de comunicación más eficientes.

Basado en Mohammed, Hasan y Hamza (2024) · Instrumentation Mesure Métrologie 23(4) · DOI 10.18280/i2m.230406

El problema real

Enviar datos sin agotar las baterías.

¿Qué es una WSN?

Muchos sensores pequeños (temperatura, humedad, movimiento) que envían datos a un nodo central, el sink.

¿Qué dificultad hay?

Transmitir gasta batería. Si algunos nodos se agotan, la red pierde conexiones.

¿Qué se busca?

Rutas de menor costo energético para que la red dure más.

Demo ilustrativa: los nodos cercanos al sink retransmiten más y se agotan primero.

¿Cómo entra el grafo?

Convertimos sensores y conexiones en un modelo que un algoritmo puede analizar.

Vértice (nodo): un sensor.

Arista: conexión inalámbrica entre dos sensores.

Peso: costo de usar esa conexión; aquí, energía.

Grafo ponderado: cada arista tiene un peso.

El camino mínimo suma el menor costo, no necesariamente el de menos conexiones.

¿Qué hace Dijkstra?

Encuentra el camino de menor costo desde un origen: elige, actualiza, repite.

import heapq

def dijkstra(grafo, origen):
    dist = {n: float("inf") for n in grafo}
    dist[origen] = 0
    previo = {}
    cola = [(0, origen)]
    while cola:
        costo, u = heapq.heappop(cola)
        if costo > dist[u]:
            continue              # ya resuelto
        for v, peso in grafo[u]:
            nuevo = costo + peso
            if nuevo < dist[v]:  # ruta mejor
                dist[v] = nuevo
                previo[v] = u
                heapq.heappush(cola, (nuevo, v))
    return dist, previo

import math

L = 1024                    # paquete de 128 bytes
E_ELEC, E_AMP = 50e-9, 100e-12

def costo_energia(d):       # d = distancia en metros
    e_tx = (E_ELEC + E_AMP * d**2) * L   # transmitir
    e_rx = E_ELEC * L                    # recibir
    return e_tx + e_rx

def construir_grafo(pos, alcance=100, agotados=()):
    grafo = {i: [] for i in pos}
    for i in pos:
        for j in pos:
            d = math.dist(pos[i], pos[j])
            if i != j and d <= alcance and j not in agotados:
                grafo[i].append((j, costo_energia(d)))
    return grafo

Conclusión

El camino mínimo depende de lo que representa el peso: aquí, la energía, no solo la distancia.

Modelar

Nodos = sensores, aristas = conexiones, pesos = costo energético.

Calcular

Dijkstra compara rutas y halla la de menor costo según el modelo.

Aplicar

Rutas más eficientes ayudan a que la red funcione más tiempo.

Ojo: funciona mejor con topologías estables; en redes muy dinámicas o con varios criterios a la vez, el artículo sugiere que ACO puede preferirse.
