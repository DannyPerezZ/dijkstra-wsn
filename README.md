# Dijkstra para ahorrar energía en redes de sensores

Presentación interactiva (HTML + JavaScript, sin dependencias) basada en:
Mohammed, Hasan y Hamza (2024), *Instrumentation Mesure Métrologie* 23(4), 307–316.
DOI: https://doi.org/10.18280/i2m.230406

## Cómo verla
Abrir `index.html` en el navegador (F11 para pantalla completa). Flechas del teclado para avanzar.

## Cómo publicarla (elige una)
**Netlify Drop (más rápido):** entra a https://app.netlify.com/drop y arrastra esta carpeta o el .zip. Te da un enlace público.
**GitHub Pages:** sube estos archivos a un repositorio nuevo > Settings > Pages > Branch `main` / carpeta `/ (root)` > Save.
**Cloudflare Pages:** Workers & Pages > Create > Pages > Upload assets > sube la carpeta.

## Para Genially
Con el enlace público, usa un elemento de incrustación (embed) con:
`<iframe src="TU_ENLACE" width="100%" height="100%" style="border:0" allowfullscreen></iframe>`
